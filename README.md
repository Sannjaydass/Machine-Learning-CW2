# 6001CMD Bank Marketing Machine Learning Project

## Introduction
This project focuses on predicting whether a customer will subscribe to a bank term deposit using machine learning. I used the UCI Bank Marketing dataset to understand customer information and prepare the data for model training.

## My Contribution
**Name: Visveswaran**

For my part, I worked on exploring the dataset and preparing the data for machine learning. I used Python to check the customer information, subscription results and patterns in the dataset. I also generated graphs to understand the data better.

For preprocessing, I worked on preparing numerical and categorical data, handling missing values, encoding categorical features and scaling numerical features. The data was then prepared for training and testing.

## My Python Files
- `eda.py` - Used to analyse the dataset and generate graphs.
- `preprocessing.py` - Used to prepare the dataset for machine learning.
- `figures/` - Contains the EDA graphs.
- `data/` - Contains the dataset and processed data where permitted to share.

## Dataset
I used the UCI Bank Marketing dataset. It contains 41,188 records. The target is whether the customer subscribed to a term deposit.

Dataset link: https://archive.ics.uci.edu/dataset/222/bank+marketing

## How to Run
1. Download the files and open the folder in PyCharm.
2. Install the required Python libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Put `bank-additional-full.csv` inside the `data` folder.
4. Run `eda.py` to generate the graphs.
5. Run `preprocessing.py` to prepare the data.

## Tools Used
Python, PyCharm Community Edition, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn.
